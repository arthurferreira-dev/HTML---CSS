Qual é a ordem da shorthand flex ?

A ordem é flex = flex-grow + flex-shrink + flex-basis .

O seu padrão é flex: 0 1 auto; ou flex: initial;

Com o elementos não flexíveis é flex: 0 0 auto; ou flex: none;

Com o elemento flexível no máximo é flex: 1 1 auto; ou flex: auto;


Com qualquer valor:

flex: 3; = flex: 3 1 auto;

flex: 17; = felx: 17 1 auto

etc...
