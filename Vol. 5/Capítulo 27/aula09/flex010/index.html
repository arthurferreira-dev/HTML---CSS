O que eles são?

A propriedade em CSS flex-shrink encolhe o item flexível quando o espaço disponível é menor que o necessário para exibir todos os itens. O valor padrão é 1, o que significa que os itens podem encolher para se ajustar ao espaço disponível. Se definido como 0, o item não encolherá, mantendo seu tamanho original.

A propriedade CSS flex-grow permite que os itens flexíveis cresçam para preencher o espaço disponível. O valor padrão é 0, o que significa que os itens não crescerão além do seu tamanho base. Se definido como 1, o item pode crescer para ocupar o espaço restante no contêiner flexível.
